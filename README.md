# Pladdra Website

Single-file, self-contained static site. No build step required.

## Usage
Open `index.html` directly in a browser, or deploy as-is to any static host
(GitHub Pages, Netlify, Vercel, S3, etc.).

### GitHub Pages
1. Push this repo to GitHub.
2. Repo Settings → Pages → Deploy from branch → `main` / root.
3. Site will be live at `https://<user>.github.io/<repo>/`.
